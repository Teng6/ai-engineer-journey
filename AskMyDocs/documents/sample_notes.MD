# Rectangle

To find the area of a rectangle, multiply length by width.

Example: length 5, width 3, area is 15.

To find the perimeter, add all four sides.

# Python List

A list holds many items in one variable. Items are in order.

```python
# make a list
fruits = ["apple", "banana", "mango"]
print(fruits[0])
```

The first item is at index 0. So `fruits[0]` is "apple".

# Python Function

A function is a block of code with a name. You run it by calling its name.

```python
def greet(name):
    return "Hello " + name
```

Use `return` to send a value back to the caller.

# Fraction

A fraction has a top number and a bottom number. The top is the numerator. The bottom is the denominator.

To add fractions with the same bottom, add the tops. Keep the bottom the same.

Example: 1/5 + 2/5 = 3/5.
